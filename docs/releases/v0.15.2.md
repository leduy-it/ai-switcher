# Michael Le Profiles 0.15.2

This patch fixes desktop backend discovery and prevents false credential-switch confirmation
when a separate CLI daemon shares the desktop's profile.

Profiles now reads the desktop's own bundled app-server child and supports current JSON daemon
PID records. It checks controller ownership before reading identity, inspecting active work or
attempting recovery. A private desktop backend that cannot be controlled reports that active work
must finish and the desktop must be closed before applying the selected account.

CLI selection and desktop application remain separate. Enable apply-on-selection explicitly if
desktop handoffs should follow account selection. This release does not enable it automatically.

Validation: seven focused Rust regressions and the frontend production build. An isolated real
Codex subprocess harness with synthetic OAuth credentials and a loopback provider checks identity
A, interruption, restart under B, same-thread resume, inference using B, persisted acknowledgement
on retry and unchanged credential files. It does not use real credentials or provider quota.

Native desktop UI handoff and recovery of client-owned tools are not validated by this harness.
Private desktop transport remains unsupported for automatic continuation; finish that work and
close the desktop before applying an account.

The universal macOS DMG supports Apple Silicon and Intel. Existing accounts and local histories
are retained. The app remains unsigned and not notarized.
