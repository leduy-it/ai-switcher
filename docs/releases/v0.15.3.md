# Michael Le Profiles 0.15.3

Use **Find a local chat** under the Codex desktop account controls when a chat disappears from
the sidebar while work is still running. Search by title, topic, project folder or chat ID, then choose
**Open chat** and continue in the original conversation.

The finder reads chat metadata from the shared Codex store and known OAuth profile catalogs,
including hidden originals. It stays available during pending handoffs and private backend errors.
It does not stop Codex, change accounts, migrate history or send a continuation prompt. Duplicate
IDs use current shared-store metadata, and unreadable catalogs are reported. Profile-only history
is marked for safe repair after work finishes. **Repair older session history** remains a separate
operation for those older catalog/history imports.

This adds a way to reopen an existing local chat while the desktop remains busy. Automatic live
sidebar synchronization and private desktop transport recovery remain unverified/unsupported;
opening a chat does not confirm that a desktop credential switch occurred.

Three focused SQLite regressions and the frontend build passed. A universal arm64/x86_64 .app
was built and packaged as a verified ZIP. Local DMG creation could not access macOS disk-image
services. Build and validation evidence is tracked in TASKS.md. Local packages do not update
the installed app, GitHub Releases or Homebrew. The macOS build remains unsigned and not notarized.
