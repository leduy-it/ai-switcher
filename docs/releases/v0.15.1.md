# Michael Le Profiles 0.15.1

This patch fixes local Codex chats disappearing from the desktop sidebar after switching
credentials, even though their conversation files were still on disk.

Profiles now merges missing desktop placement records, including chats outside projects and
state copies retained by older versions. A safe desktop handoff prepares a regular private state
snapshot after normal quit and refreshes the incoming profile's local chat catalog scan. This
preserves older restored timestamps and survives Codex's atomic file saves.

The session-repair result reports recovered sidebar records separately. After repairing missing
chats, finish active desktop work and reapply the account to refresh its list. OAuth credentials
remain separate; API/proxy profiles remain isolated. This patch does not restart active desktop
work during repair or continue completed sessions.

Validation: frontend production build and three focused regression tests for atomic-save
handoffs, legacy state recovery, credential isolation and local-only cache refresh. Live credential
switching with active desktop work was not exercised.

Download the universal macOS DMG from the release assets, or update with:

```sh
brew upgrade --cask --greedy leduy-it/ai-switcher/michael-le-profiles
```

The app remains unsigned and not notarized. Existing accounts and local histories are retained.
